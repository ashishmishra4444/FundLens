# MyFutureFund 📈

A goal-based SIP and investment planning platform that educates users on **how, why, and when** to invest using behavioral finance insights.

---

## 🚀 Features
- Goal-based SIP planning
- Delay cost simulation
- Step-up SIP analysis
- Missed SIP impact
- Inflation-adjusted returns
- JWT & Google OAuth authentication
- Interactive dashboard
- Dark mode (WCAG compliant)

---

## 🛠 Tech Stack

### Frontend
- React 18
- shadcn/ui
- Tailwind CSS
- Context API
- Recharts

### Backend
- Node.js
- Express
- MongoDB
- Mongoose Aggregation
- JWT + bcrypt

---

## 🤝 Team Workflow
- Development happens on `dev` branch
- Stable code is merged into `main`
- `main` branch is deployed
